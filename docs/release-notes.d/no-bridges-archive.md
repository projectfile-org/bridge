The `pf-bridge-bridges-<version>-<os>-<arch>.tar.gz` archives announced in v4.0.0 are not published. The single-bridge binaries in them weighed about 130 MB per platform, eight times the standalone `pf-bridge-<os>-<arch>`, which already includes every bridge. Download that one binary; to get the single-bridge binaries, build them from source.
