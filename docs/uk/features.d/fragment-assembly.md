# Збирання фрагментів можливостей і дорожньої карти

- Збирає файли фрагментів `docs/*.d/*.md` у складені документи на кшталт FEATURES.md і ROADMAP.md.
- Вкладає опубліковане батьківськими репозиторіями, отримане наживо за їхнім найновішим тегом випуску — зафіксований документ єдиний запис, тож повторна генерація і є способом, яким прибувають зміни батька.
- Отримання потребує лише найновішого тега батька й одного запиту архіву — без API форжу чи таблиці URL — а перевірка лишається поза мережею, перечитуючи зафіксовані розділи.
