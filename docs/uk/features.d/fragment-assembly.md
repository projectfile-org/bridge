# Збирання фрагментів можливостей і дорожньої карти

- Збирає файли фрагментів `docs/*.d/*.md` у складені документи на кшталт FEATURES.md і ROADMAP.md.
- Вкладає успадкований від батьківських репозиторіїв вміст за тегом випуску; віндоровані копії зафіксовані для офлайн-відтворюваності.
- Оновлення успадкованих копій потребує лише найновішого тега батька та одного запиту архіву — без API форжу чи таблиці URL для кожного форжу.
