# Починай за хвилини, лишайся в синхроні потім

- Новий проєкт починається з інтерактивного помічника, що визначає екосистему й пропонує посилання форжів і реєстри з адреси репозиторію та стеку.
- Сканери читають робочу копію — стек, авторів, віддалені адреси — назад у projectfile, тож документ починається правдивим і лишається правдивим.
- Одна команда оновлює кожен згенерований файл; названий один — оновлюється лише той файл.
- Перевірка генерує без запису й показує кожен змінений або відсутній файл як diff, завершуючи збірку помилкою, коли ти просиш.
