# З ліцензією та готовий до цитування

- `LICENSE` записується з твоїм правовласником і роком на місці, тож опублікований файл — це готовий текст, а не шаблон.
- Повний текст кожного ліцензійного терміна, який ти декларуєш, постачається поруч під `LICENSES/`, по одному файлу на термін.
- `CITATION.cff` тримається в синхронізації, тож дослідники цитують проєкт правильно без зайвих зусиль з твого боку.
