# Нотатки до випуску, написані з твоєї історії

- Кожна сторінка випуску містить однакові нотатки на кожній платформі: що змінилося, що нового і що ламає оновлення.
- Команди встановлення та перевірки прив’язані до цієї точної версії та дайджесту образу, тож їх можна вставляти як є.
- Для кожної архітектури вказано дайджест і розмір, а сторінка показує, що зросло, зменшилося чи оновилося з попереднього випуску.
- Перегляньте нотатки перед позначенням тегом; випускається саме та сторінка, яку ви перевірили.
