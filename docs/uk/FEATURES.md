# Можливості

## Можливості проєкту

### Ідентичність форжу, сканування та каркаси

- Надсилає ідентичність проєкту на GitHub, GitLab і Forgejo.
- Запускає сканери файлової системи та Git над робочою копією.
- Інтерактивно створює новий projectfile, автоматично визначаючи екосистему та виводячи посилання форжів і реєстри з URL репозиторію та стеку.
- Генерує перекладені варіанти громадських документів з однієї декларації мови; іспанська та українська вбудовані.

### Збирання фрагментів можливостей і дорожньої карти

- Збирає файли фрагментів `docs/*.d/*.md` у складені документи на кшталт FEATURES.md і ROADMAP.md.
- Вкладає опубліковане батьківськими репозиторіями, отримане наживо за їхнім найновішим тегом випуску — зафіксований документ єдиний запис, тож повторна генерація і є способом, яким прибувають зміни батька.
- Отримання потребує лише найновішого тега батька й одного запиту архіву — без API форжу чи таблиці URL — а перевірка лишається поза мережею, перечитуючи зафіксовані розділи.

### Проєкція projectfile у файли

- Генерує та підтримує двонаправлені зовнішні файли, яких очікує форж, з одного документа projectfile: маніфести пакунків, CITATION.cff, LICENSE плюс тексти за ліцензіями SPDX, родина gitignore, readme та громадські документи.
- Синхронізує кожен зовнішній файл у обох напрямках; одна команда оновлює все — або один файл за ім’ям.
- Перевірка дрейфу рендерить без запису та звітує про кожен здрейфований або відсутній файл уніфікованим diff-ом, завершуючись помилкою за потреби.
